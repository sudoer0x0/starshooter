# Star Shooter

A fast-paced retro-arcade space shooter built with HTML5 Canvas, Web Audio API, and vanilla JavaScript. Optimized for desktop and mobile touch controls.

## Features

- **Retro Arcade Gameplay**: Wave-based combat, enemy attack formations, elite variants, and flagship boss encounters.
- **Dynamic HUD**:
  - Responsive, compact top HUD designed to never overlap or clip on mobile or desktop.
  - Floating arcade combo multiplier (`×n`) with dynamic hit scaling and smooth transparent fade.
  - Circular progress gauges for active booster durations (`Rapid Fire`, `Multi-Shot`, `Shield`).
  - Circular boss core status indicator.
- **T-R-I-S-T-E-S-S-E-E Super Booster**:
  - Collect falling booster letters to fill the word matrix.
  - Illuminates letters upon collection with a circular completion ring.
  - Completing the sequence unleashes a 10-second Super Booster overdrive.
- **Controls**:
  - **Desktop**: Mouse or Arrow keys / WASD to steer, Space or Left Click to fire.
  - **Mobile**: Touch drag to steer and continuous auto-aim/firing with on-screen virtual controls.
  - **Pause**: Press `P` or tap the Pause button.

## How to Play

Open `index.html` in any modern web browser or visit the GitHub Pages deployment.
